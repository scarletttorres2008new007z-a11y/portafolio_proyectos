★ Perfil

Quién soy

Soy Scarlett Torres, diseñadora y desarrolladora web, y estudio Técnico en Computación en la Universidad Don Bosco. Me especializo en transformar ideas en sitios modernos, funcionales y con personalidad para marcas, emprendimientos y negocios locales.

He diseñado y publicado 8 proyectos para industrias muy distintas. El más completo es Café Don Bosco, un sistema en Java con tienda en línea, panel de administración, inventario y 83 pruebas unitarias. También he hecho sitios para un cine de autor, una clínica dental, una floristería, dos barberías, otra cafetería y turismo. En cada uno cuido tanto el diseño como lo que el sitio hace: reservas, compras, cotizadores y paneles de gestión.

Mi aprendizaje no se detiene. Sigo explorando nuevas tecnologías y herramientas para ofrecer mejores soluciones en cada proyecto.

★ Experiencia

Proyectos publicados

  1. Web + sistema · Cafetería

    Café Don Bosco

    Sistema web completo para una cafetería: una tienda en línea donde el cliente personaliza su pedido y paga sin crear cuenta, y un panel de administración con punto de venta, inventario e historial. Todo comparte la misma base de datos. Ver caso · cafe-don-bosco-production.up.railway.app

  2. Sitio multipágina · Cine y entretenimiento

    Lumière Ciné

    Sitio para un cine de autor con cartelera por día, compra de entradas con selección de asientos y membresía con tarjeta de miembro. Se siente como entrar a la sala. Ver caso · lumiere-cine-sv.netlify.app

  3. Web + sistema · Salud dental

    AEOD Odontología

    Landing para una clínica dental con solicitud de citas, cuestionario de orientación y estimador de costos, conectada a un backend con software de gestión para el personal. Ver caso · aeodlanding.netlify.app

  4. Landing page · Floristería

    Casa Pétalo

    Landing para una floristería con catálogo filtrable y un constructor para armar tu propio ramo con vista 3D y precio en tiempo real. El pedido llega completo a WhatsApp. Ver caso · floristerialanding.netlify.app

  5. Landing page · Barbería

    NAVAJA Barber Studio

    Landing para una barbería con reservas por WhatsApp, una galería para elegir tu corte y una vista 360 que se gira arrastrando. Ver caso · lanavajacut.netlify.app

  6. Sitio multipágina · Turismo

    Descubre El Salvador

    Sitio turístico de seis páginas sobre destinos, cultura e historia de El Salvador, con galería, línea de tiempo y un formulario para planificar el viaje. Ver caso · descubreelsalvador.netlify.app

  7. Landing page · Cafetería

    Cielo de Flores

    Sitio para una cafetería y pastelería en Antiguo Cuscatlán, con menú, promos, galería y un recomendador que te sugiere qué pedir según tu antojo. Primero una demo y después el sitio completo. Ver caso · cafeflores.netlify.app

  8. Landing page · Barbería

    El Caballero

    Landing para una barbería clásica con servicios y precios, galería de trabajos y un formulario de reserva que envía la cita por WhatsApp. Ver caso · elcaballerobarber.netlify.app
